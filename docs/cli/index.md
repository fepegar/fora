# CLI Overview

The `fora` command is the main entry point. Running it with no subcommand starts the interactive terminal UI. Subcommands are available for specific tasks.

## Usage

```bash
# Start the TUI
fora

# Run a subcommand
fora <command> [options]
```

## Commands

| Command | Description |
|---------|-------------|
| [`fora`](./tui) | Start the interactive terminal UI |
| [`fora init`](./init) | Interactively set up a configuration file |
| [`fora submit`](./submit) | Submit a job to Azure ML |
